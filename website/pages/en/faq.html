Frequently asked questions

Is WParted free?

Yes. WParted is free software under the GPL-2.0-or-later licence. There is no paid edition.

Can WParted resize, move or delete partitions?

On disk image files, yes: version 0.2 creates, deletes, moves, copies and resizes partitions there (FAT and NTFS file systems are resized too). On physical disks it plans and validates, but does not execute yet.

Does WParted change my disks?

No. The current version only reads physical disks; continuous integration rejects any code that would write to a device. It writes only to disk image files you open and confirm twice.

Does WParted run on Windows 7?

Windows 7 SP1 is a build target, but it has not yet been verified on a real Windows 7 system. So far WParted has been verified on Windows 11 x64.

Is WParted related to GParted?

No. WParted is an independent project that follows GParted's workflow and design ideas. It contains no GParted code.

Can WParted read Linux partitions?

It detects ext2/3/4, btrfs, XFS, swap, LUKS, LVM and other file systems and shows their labels. Changing them will require the planned offline mode.

Can WParted recover a deleted partition?

Version 0.2 contains a read-only rescue scan that finds file systems in unallocated space. Recovery itself is not automated yet.

Does WParted collect data or need an internet connection?

No. WParted has no telemetry, does not connect to the network and needs no account.
