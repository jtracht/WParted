WParted: a GParted-style partition manager for Windows

WParted is a free and open-source partition manager for Windows. It shows disks, partition tables, file systems and volumes the way GParted does, as a small native program without installation.

Why another partition manager?

GParted is the reference for clear, honest partition editing, but it runs on Linux. On Windows, users choose between the limited Disk Management console and closed-source tools. WParted aims for GParted's workflow and transparency as a native, portable Windows program, and every feature is released only after tests on disk images and virtual disks.

Safety first

  • Physical disks are only read; CI rejects any device write API. Changes go to image files after two confirmations.
  • Plans identify disks by serial number, size and partition table ID, not only by disk number.
  • System partitions, the running Windows volume, BitLocker and dynamic disks are refused.
  • Agents and automated tests never write to physical disks.
