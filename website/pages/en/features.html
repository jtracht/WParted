Features and status

This page lists what WParted can do today. Anything not listed as available is planned and will only be enabled after tests on disk images and virtual disks.

Available in {{version}}

FeatureDetails
Disk overviewPhysical disks with model, interface, sector sizes, SSD/HDD, write protection, volumes and mount points.
Partition tablesGPT (CRC check, backup header), MBR with extended/logical partitions, detection of Apple, BSD, Sun and other tables.
File systemsSignature detection for 31 types incl. NTFS, FAT, exFAT, ReFS, BitLocker, ext2/3/4, btrfs, XFS, LUKS, LVM, APFS and HFS+.
DiagnosticsDamaged GPT headers, overlaps, sector-size mismatch of USB enclosures, differences to the Windows view.
ReportsJSON report export; command line tool wparted-cli with JSON output.
InterfaceGParted-style layout, light and dark theme, English and German, high-DPI.
