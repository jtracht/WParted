Which file?

  • …-win7plus-x64-portable.zip: 64-bit Windows (almost all PCs).
  • …-win7plus-x86-portable.zip: 32-bit Windows.
  • …-checksums.sha256: SHA-256 checksums; …-sbom.cdx.json: software bill of materials.

Install in three steps

  1. Download the ZIP and check it: certutil -hashfile WParted-….zip SHA256 must match the checksum file.
  2. Extract it to any folder. No installer or runtime is needed.
  3. Start wparted.exe. To read partition tables, choose Restart as Administrator.

Known limitations

  • The binaries are not code-signed yet; Windows SmartScreen may warn.
  • The release binaries were tested under Wine in CI; an equivalent build was run on Windows 11. Windows 7 to 10 are not verified yet.
  • Administrator mode has not yet been verified against real disks.
