Häufige Fragen

Ist WParted kostenlos?

Ja. WParted ist freie Software unter der Lizenz GPL-2.0-or-later. Eine kostenpflichtige Ausgabe gibt es nicht.

Kann WParted Partitionen verkleinern, verschieben oder löschen?

Noch nicht. Entwicklungs-Builds können diese Operationen planen und prüfen, aber nicht ausführen. Die Ausführung wird erst freigeschaltet, wenn sie Tests auf Abbildern und virtuellen Datenträgern bestanden hat.

Verändert WParted meine Datenträger?

Nein. Die aktuelle Version liest nur. Die Continuous Integration lehnt in diesen Builds jeden Code ab, der auf einen Datenträger schreiben würde.

Läuft WParted unter Windows 7?

Windows 7 SP1 ist Build-Ziel, wurde aber noch nicht auf einem echten Windows-7-System geprüft. Bisher ist WParted unter Windows 11 x64 geprüft.

Gehört WParted zu GParted?

Nein. WParted ist ein unabhängiges Projekt, das dem Bedienkonzept von GParted folgt. Es enthält keinen GParted-Code.

Kann WParted Linux-Partitionen lesen?

Es erkennt ext2/3/4, btrfs, XFS, Swap, LUKS, LVM und weitere Dateisysteme und zeigt ihre Bezeichnungen. Änderungen erfordern den geplanten Offline-Modus.

Kann WParted eine gelöschte Partition wiederherstellen?

Entwicklungs-Builds enthalten einen nur lesenden Rettungs-Scan, der Dateisysteme im nicht zugeordneten Bereich findet. Die Wiederherstellung selbst ist noch nicht automatisiert.

Sammelt WParted Daten oder braucht es eine Internetverbindung?

Nein. WParted hat keine Telemetrie, verbindet sich nicht mit dem Netzwerk und braucht kein Konto.
